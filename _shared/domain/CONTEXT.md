# Domain references

This template selects no product domain. During setup or feature work, record
accepted shared vocabulary and invariants in narrowly scoped files here and
link them from this catalog. Keep a decision in its Project brief until it
actually constrains several Projects.

Use product concepts to name code and interfaces. Resolve ambiguous terms with
their owner; do not infer domain rules from UI labels or copied example data.
No domain-specific rules have been registered in the source template.
