# Architecture investigation

Use only when material uncertainty needs a separate evidence owner. Keep a
Project's evidence with its brief; use `architecture/investigations/` only when
no Project is its natural owner. Findings do not replace accepted decisions.
Remove these prompts when creating the artifact.

## Question and scope

Decision blocked, affected owners, existing evidence, credible alternatives,
effort limit, evidence target, and stop condition. Link the original authority
under the shared investigation limit; no duplicate approval receipt.

## Findings

Exact experiment or research evidence, observed results, limitations, and the
material costs of credible alternatives. Distinguish fact from recommendation.

## Disposition

Chosen response and its human source, affected decisions, remaining uncertainty,
and the next useful action. Promote experimental code only through accepted
technical decisions and normal implementation proof.

## Canonical owners

Link the brief, earned ADR, or shared source changed. If this document itself
owns a Project decision, list its Project-relative path in `decision_documents`.
