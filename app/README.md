# Application code

This path reserves the application boundary in an unconfigured factory. The
application stack and final source layout have not been selected.

During setup for an existing repository, preserve its verified source layout
and update the root route to that canonical location. For a new repository, let
the first applicable Technical Specification choose the stack and source
layout, then place code here or replace this route with the selected path.

Do not create placeholder application code, dependency configuration, provider
settings, or example secrets merely to populate this folder.
