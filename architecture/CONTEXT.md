# Repository architecture work

This folder holds working architecture spikes that affect several Projects and have no natural parent Project.

- Working spike evidence: `spikes/<spike-slug>/`
- Accepted cross-Project decisions: `../_shared/architecture/decisions/`
- Reusable decision and spike rules: `../_shared/architecture/decision-rules.md` and `../workflows/architecture-spike/references/spike-rules.md`

Prefer a Project-local spike whenever one Project naturally owns the question. Do not place Project-specific specifications or implementation here.
