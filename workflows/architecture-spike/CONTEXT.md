# Architecture spike — interrupt unresolved architecture work

One job: route a narrow, evidence-producing architecture interruption without creating another Project.

| Substage | Job | Output | Human check |
|---|---|---|---|
| [`01_frame`](01_frame/CONTEXT.md) | Define the blocked decision and impact scope | Spike brief | Approve the question and hold |
| [`02_investigate`](02_investigate/CONTEXT.md) | Gather the minimum discriminating evidence | Findings | Confirm the evidence is sufficient |
| [`03_decide`](03_decide/CONTEXT.md) | Reconcile a human decision into canonical sources | Decision summary, specification updates, and optional ADR | Approve the decision and Project routes |

Run the substages in order. Investigation may repeat without creating a Project build iteration. After Decide, each affected Project resumes at its earliest invalidated lifecycle stage.
